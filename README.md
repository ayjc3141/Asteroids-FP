# Welcome to Multiplayer Asteroids!
## How to run the game

To run our take on asteroids, you will have to follow a few steps:
1. Make sure you have GHC and Cabal installed. If you do not have them installed, you can follow the instructions [here](https://www.haskell.org/ghcup/).
2. Download and extract the ZIP file.
3. Open the extracted folder and open a terminal in said folder (the folder where ProjectFunctioneel.cabal is located).
4. In the terminal run `cabal build` and press enter.
5. Run `cabal run ProjectFunctioneel` and press enter again. The game should be running on your screen now!

## Game controls

|Control|Player 1|Player 2|
|-------|--------|--------|
|Move Forward| Arrow Up | W |
|Turn Left| Arrow Left | A |
|Turn Right| Arrow Right| D |
|Shoot| Spacebar | C |

To pause/unpause the game, press P.

The goal of the game is to destroy as many enemies as possible. 
The more enemies you destroy, the more points you get. 
The two players have shared lives, meaning if one gets hit, both will lose a live! The game ends when all lives are lost.

Have fun!
